在现有 gapless 骨架上，把它做成一个能把多段音频拼成连续时间轴、并给出精确接缝坐标的拼接器。保留 Segment、load_playlist、plan_timeline、render_timeline 的现有名字与签名，
只用 Python 标准库，不得引入第三方依赖，不得改动 data/playlist.json。

## 需要完成

1. **时间轴**
   - 每段的时长由采样数与采样率决定，时间轴坐标必须精确到毫秒，累计误差不能随段数增长。
   - 段间可以配置重叠毫秒，重叠区要做交叉淡化，淡化后接缝处的能量不能突然下降。
2. **接缝**
   - 输出的接缝坐标要能被反查回原段与段内偏移，坐标与渲染出的样本索引必须一致。
   - 同一段被引用两次时，两处接缝坐标不能互相污染。
3. **异常**
   - 采样率不一致时按最高采样率重采样，或者明确报错，二者只能选一种并在 README 写清。
   - 空段、零长度段要跳过，不改变总时长。
4. **输出**
   - 输出样本数与时间轴总时长必须对得上，连续跑两次逐字节一致。

## 测试

- 覆盖：累计毫秒误差、接缝坐标反查、重叠交叉淡化、空段跳过、两次输出一致。
- `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m gapless.cli data/playlist.json --out grid.json`，把总时长、段数、各接缝毫秒坐标、最大毫秒误差贴进 README。
