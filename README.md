# 无缝拼接时间轴

一个能把多段音频拼成连续时间轴、并给出精确接缝坐标的拼接器。仅使用 Python
标准库（`dataclasses`、`fractions`、`hashlib`、`json`、`math`、`argparse`），
无第三方依赖。

## 保留签名

- `Segment(name, rate, samples)`
- `load_playlist(path) -> list[Segment]`
- `plan_timeline(segments, overlap_ms) -> dict`
- `render_timeline(segments, plan) -> dict`

另附一个反查辅助函数 `locate_sample(plan, index)`，把渲染输出中的任意样本
索引反查回原段出现序号、段名与段内偏移。

## 设计与策略说明

### 时间轴：精确到毫秒，误差不随段数累积

- 所有时间量在内部都以 `fractions.Fraction` 精确表示（采样数 ÷ 采样率），
  毫秒坐标由精确时间一次性换算，不做逐段浮点累加。
- 每个边界（段起点、段终点、总终点）只做 **一次** 四舍五入得到输出采样率下的
  整数样本索引。因此单个坐标的误差上界恒为半个采样周期
  （`500 / rate` 毫秒，48 kHz 时约 0.0104 ms），与段数无关，不存在累计漂移。

### 重叠与交叉淡化

- `overlap_ms` 配置段间重叠；重叠时长自动夹到不超过相邻两段各自的长度，
  避免淡化区越界。
- 重叠区使用 **等功率交叉淡化**：后段增益 `sin(θ)`、前段增益 `cos(θ)`，
  满足 `sin²θ + cos²θ = 1`，接缝处能量不会突然下降（测试中对真实伪噪声源
  验证重叠区与非重叠区均方能量差小于 10%）。

### 接缝反查

- 每条接缝记录输出样本索引、毫秒坐标，以及前后两段的出现序号（`occurrence`）
  与段内偏移；接缝索引与渲染输出的样本索引一一对应，可经 `locate_sample`
  反查。
- 时间轴按段在输入列表中的 **出现序号** 而不是段名定位。同一段被引用两次时
  得到两个独立布局条目，两处接缝坐标互不污染。

### 异常处理（二选一的明确选择）

- **采样率不一致：按最高采样率重采样（线性插值），不报错。** 布局条目中保留
  各段原始采样率，反查偏移同时给出输出采样率与原采样率两种坐标。
- 空段、零长度段（`samples <= 0`）在规划阶段直接跳过，不产生接缝，
  不改变总时长。
- `overlap_ms < 0` 或采样率非正时抛出 `ValueError`。

### 确定性输出

- 每段的合成波形由段名经 SHA-256 派生的 LCG 确定性生成；渲染为纯函数，
  同样输入连续渲染两次，量化后的 16-bit 样本逐字节一致（CLI 输出含
  `render_sha256` 便于校验）。
- 输出样本数与时间轴总时长严格对应：
  `total_samples / rate * 1000 == total_ms`（在取整误差范围内）。

## 实测结果

`python -m gapless.cli data/playlist.json --out grid.json`（默认 0 重叠；
清单中 `c` 为 0 采样空段，被跳过）：

| 项目 | 值 |
| --- | --- |
| 输出采样率 | 48000 Hz |
| 有效段数 | 2（共 3 段，空段 `c` 跳过） |
| 总时长 | 1500.000 ms |
| 总样本数 | 72000 |
| 最大毫秒误差 | 0.000000 ms |

各接缝毫秒坐标：

| 接缝 | 样本索引 | 毫秒坐标 | 前段 → 后段 | 前段内偏移 | 重叠 |
| --- | --- | --- | --- | --- | --- |
| #1 | 48000 | 1000.000 ms | `a` → `b` | 1000.000 ms / 第 48000 样本 | 0 |

带重叠示例（`--overlap-ms 100`）：总时长缩短为 1400.000 ms，接缝位于
900.000 ms（样本 43200），重叠 4800 个采样。

## 自测

```
python -m pytest tests -q
python -m gapless.cli data/playlist.json --out grid.json
```

测试覆盖（15 项，全部通过）：累计毫秒误差不随段数增长、接缝坐标反查、
接缝索引与渲染样本一致、同名段重复引用隔离、等功率交叉淡化恒等式与能量
不下跌、重叠长于短段时自动夹取、空段/全空清单跳过、两次渲染逐字节一致、
混合采样率重采样到最高率、非法参数报错。
